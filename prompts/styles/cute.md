# 스타일 지침 — 귀여운 둥근 스타일

모서리가 없고 모든 덩어리가 부풀어 있다. 머리·지붕·뚜껑처럼 **위쪽 덩어리가 아래보다
크고**, 지지 부위는 짧고 통통하다. 파스텔에 가까운 밝은 색과 부드러운 명도 대비로
읽히며, 날카로운 각·가느다란 파트·어두운 색은 이 스타일을 깨뜨린다.

1. **모든 큰 파트에 베벨을 넣어라**: 실루엣을 이루는 파트마다 `lp.bevel(obj, width=0.02~0.05, segments=2)`를 적용하라. 로우폴리와 정반대의 규칙이다 — 날카로운 모서리가 남아 있으면 귀엽게 읽히지 않는다. 아주 작은 디테일(0.05m 미만)은 생략해도 된다.
2. **둥근 프리미티브 우선**: `lp.sphere`(subdivisions=2)·`lp.lathe(smooth=1~2)`·`lp.cylinder(segments=12~16)`를 기본으로 쓰고, `box`는 베벨을 넉넉히 준 경우에만 쓴다. `prism`의 뾰족한 꼭짓점은 피하라.
3. **부풀리기는 필수**: 주 질량에 `lp.bulge(amount=0.15~0.35, center=0.5~0.65)`를 적용해 가운데나 위쪽이 통통하게 부풀게 하라. 원통을 그대로 두면 딱딱하다.
4. **역삼각 비율 (귀여움의 공식)**: 상단 덩어리(머리·지붕·잎·뚜껑)를 하단 대비 **150~200%**로 키우고, 지지 부위(다리·기둥·줄기)는 짧고 굵게 — 길이는 전체 높이의 25% 이하, 굵기는 사실 대비 130% 이상. 가늘고 긴 파트를 만들지 마라.
5. **뾰족한 끝 금지**: `lp.taper`로 끝을 좁히더라도 factor 0.5 이하로 완전히 뾰족하게 만들지 마라(0.6~0.8 권장). 원뿔은 `radius_top`을 0으로 두지 말고 반지름의 20~30%를 남겨라.
6. **폴리 버짓 (트라이 기준)**: 모델 전체 ≤ 20000. 둥근 실루엣과 베벨에 트라이가 필요하다 — 로우폴리보다 넉넉하게 잡았으니 세그먼트를 아끼지 마라. 단 눈에 띄지 않는 뒷면·바닥에는 투자하지 마라.
7. **색은 밝고 채도 중간, 명도 대비를 좁게**: 파스텔~중간 채도(너무 탁하지도 형광도 아니게), 명도는 전반적으로 밝게. 같은 재질의 2톤 차이를 로우폴리보다 **좁게** 줘라 — 대비가 세면 귀여움이 사라지고 딱딱해진다. 어두운 색은 눈·입·테두리 같은 작은 포인트에만 쓴다.
8. **얼굴 요소가 있으면 크게**: 대상에 눈이 있으면(동물·캐릭터·의인화 프랍) 눈은 머리 폭의 **20~30%** 크기로 크고 둥글게, 좌우로 벌려 배치하라. `lp.mirror_x`로 대칭을 보장한다.

## 좋은 예시 (참고 패턴)

```python
# 귀여운 버섯 집: 역삼각 비율(갓 180%) + 전면 베벨 + 부풀린 몸통 (시그니처: 둥근 갓 + 아치문 + 물방울무늬)
stem = lp.lathe("Stem", profile=[(0.42, 0.0), (0.46, 0.25), (0.40, 0.6)], segments=14, smooth=1)
lp.bulge(stem, amount=0.22, center=0.4)          # 몸통은 아래가 통통하게
lp.bevel(stem, width=0.03, segments=2)
lp.set_color(stem, (0.96, 0.93, 0.85))
cap = lp.lathe("Cap", profile=[(0.0, 1.15), (0.55, 0.92), (0.78, 0.72), (0.74, 0.58)],
               segments=16, smooth=2)             # 갓은 몸통 폭의 180% — 역삼각 비율
lp.bevel(cap, width=0.04, segments=2)
lp.set_color(cap, (0.94, 0.45, 0.45))
dots = []
for i, (x, y, z) in enumerate([(0.3, 0.2, 0.95), (-0.28, 0.25, 0.9), (0.05, -0.35, 1.0)]):
    dot = lp.sphere(f"Dot{i}", radius=0.12, subdivisions=2, location=(x, y, z))
    lp.set_color(dot, (0.99, 0.97, 0.92))         # 포인트 색은 밝게
    dots.append(dot)
door = lp.lathe("Door", profile=[(0.0, 0.42), (0.16, 0.34), (0.18, 0.0)], segments=12, smooth=1,
                location=(0, -0.40, 0))           # 아치문 — 뾰족하지 않게
lp.set_color(door, (0.62, 0.44, 0.32))
house = lp.join([stem, cap, *dots, door], name="MushroomHouse")
```
