# 캐릭터 템플릿과 부위 분리

## 복구한 요청

Claude 세션 `4ea4404c-529e-455b-aeb0-140b7c019254`의 마지막 승인:
인간형·네발형 베이스 메시를 직접 제작하고 사용자가 별도로 등록하거나 수정할 수 있게 한다.
몸체 / 의상·갑옷 / 무기를 분리 생성한다. 얼굴은 촘촘하게, 팔다리는 성기게,
관절에는 변형용 루프가 있어야 한다. 기존 구현 기준은 commit `99217ce`다.

## 설계

- 외부 유료 에셋 대신 자체 제작 쿼드 템플릿을 제공한다. 얼굴·관절 밀도를 형상 구조에
  반영하고 부위 vertex group을 제공한다. 템플릿은 씬으로 불러와 Edit Mode에서 수정할 수 있다.
- 선택한 메시를 사용자 `.blend` 템플릿으로 등록한다. 외부 `.blend` 파일도 등록한다.
  사용자 리소스에 복사해 애드온 업데이트와 분리하고 원본 파일을 덮어쓰지 않는다.
- 리토폴로지 옵션 `TEMPLATE`를 추가하고 몸체에만 적용한다. 기존 QUADRIFLOW/DECIMATE를
  유지한다. 템플릿 적합은 초기 비율 정렬과 제한된 표면 투영이며 자동 리깅 완성을 뜻하지 않는다.
- 캐릭터 3분할 모드에서는 원래 턴어라운드로부터 동일 자세·동일 뷰의 몸체/장비/무기 시트를
  생성하고 각각 Hunyuan에 요청한다. GPU 요청은 순차 실행한다. 부품은 세션 컬렉션 안의
  독립 오브젝트로 유지하고 몸체를 기준으로 크기와 위치를 맞춘다.
- 누락된 부위나 템플릿 오류는 사용자 로그에 드러낸다. 부분 결과를 조용히 성공으로 취급하거나
  분리 실패를 통합 메시로 숨기지 않는다. 취소된 콜백은 다음 요청을 실행하지 않는다.
- 몸체와 장비 사이 은면 제거를 하지 않아 옷 아래 몸체를 보존한다. 텍스처도 분리 부위별로
  생성·베이크해 가려진 몸체에 갑옷이 투영되지 않도록 한다.

## 검증

순수 Python 테스트: 템플릿 데이터·등록 검증·시트 프롬프트·콜백 순서·실패·취소.
격리 Blender: 등록/해제, 템플릿 생성·편집 후 재등록, 면·밀도·부위 그룹, 실제 GLB 적합,
분리 오브젝트 보존. 네트워크 생성은 실행 가능 범위와 실제 실행 여부를 구분해 보고한다.
Windows 실행기와 macOS 실행기 세트를 유지한다. 사용자 Blender 설치본을 덮어쓰지 않는다.
