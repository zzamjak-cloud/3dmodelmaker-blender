# 스타일 지침 — 스타일리쉬 캐주얼 (형태 데포르메)

Clash of Clans·Fortnite 계열의 과장된 캐주얼이다. 로우폴리보다 폴리를 더 쓰고,
**형태를 의도적으로 비틀어** 성격을 만든다. 귀여운 스타일과 달리 각과 곡선이 함께
있고, 실루엣이 기울거나 휘어 있어 정적인 느낌이 없다.

1. **기울기·휘어짐이 기본이다**: 주 질량에 반드시 `lp.shear(offset=0.15~0.35)` 또는 `lp.bend(angle=8~25)`를 적용해 수직에서 벗어나게 하라. 똑바로 선 상자·원통을 그대로 두면 이 스타일이 아니다. 건물은 위로 갈수록 한쪽으로 기울고, 나무·굴뚝·간판은 휜다.
2. **상하 대비를 극단으로**: 위쪽 덩어리(지붕·갓·머리)는 사실 대비 **160~220%**, 아래 지지 부위는 **60~80%**로 줄여라. 로우폴리의 130~160%보다 한 단계 더 밀어붙인다. `lp.stretch_at`으로 특정 높이 구간만 키우는 것이 가장 효과적이다.
3. **비대칭을 의도적으로 넣어라**: 창문 크기를 다르게, 기둥 간격을 불균등하게, 지붕 한쪽 처마를 더 길게. 완벽한 대칭은 심심하다. 단 좌우 대칭이 정체성인 대상(차량·캐릭터 정면)은 `lp.mirror_x`로 대칭을 지키고 표면 디테일에서만 비대칭을 준다.
4. **끝을 뾰족하게, 밑동을 굵게**: `lp.taper(factor=0.3~0.5)`로 위로 갈수록 급격히 좁히고 밑동은 넓게 남겨라 — 안정감 있는 삼각 실루엣이 이 스타일의 뼈대다. 귀여운 스타일의 역삼각과 반대다.
5. **모서리 처리는 선택적으로**: 실루엣을 결정하는 큰 파트에만 `lp.bevel(width=0.015~0.03, segments=1)`을 얇게 준다. 전면 베벨은 물렁해 보이므로 금지 — 각이 살아 있어야 한다.
6. **폴리 버짓 (트라이 기준)**: 모델 전체 ≤ 25000. 곡률 세그먼트(lathe·cylinder 12~20)와 디테일 파트에 충분히 투자하라. 실루엣에 기여하지 않는 내부 면에는 쓰지 마라.
7. **디테일 파트 8개 이상**: 공통 규칙의 4개보다 많다. 테두리 몰딩·리벳·밧줄·널빤지 이음·간판·깃발처럼 **표면을 읽히게 하는 작은 파트**를 반복 배치하라. `lp.array`/for 루프로 채운다.
8. **색은 4~7색, 명도 대비를 세게**: 채도 높은 주조색 2개 + 보조 2~3개 + 채도 최고의 악센트 1개. 같은 재질의 2톤 차이를 로우폴리보다 **크게** 벌려라(밝은 면과 어두운 면이 확실히 구분되게). 악센트는 시그니처 요소 한 곳에만 쓴다.

## 좋은 예시 (참고 패턴)

```python
# 스타일리쉬 대장간: 기울어진 벽 + 220% 과장 지붕 + 비대칭 처마 (시그니처: 모루 + 굴뚝 + 차양)
body = lp.prism("Body", outline=[(-1.1, 0.0), (1.1, 0.0), (0.85, 2.2), (-0.85, 2.2)], depth=1.8)
lp.shear(body, offset=0.22)                       # 위로 갈수록 기울어진 벽
lp.bevel(body, width=0.02, segments=1)
lp.set_color(body, (0.78, 0.70, 0.56))
roof = lp.prism("Roof", outline=[(-1.9, 2.0), (1.5, 2.0), (0.1, 3.6)], depth=2.3)  # 처마 좌우 비대칭
lp.set_color(roof, (0.30, 0.34, 0.42))            # 어두운 톤 — 명도 대비를 세게
chimney = lp.lathe("Chimney", profile=[(0.24, 2.4), (0.20, 3.3), (0.30, 3.5)],
                   segments=12, smooth=1, location=(0.6, 0.4, 0))
lp.bend(chimney, angle=14)                        # 굴뚝은 휘어야 정적이지 않다
lp.set_color(chimney, (0.46, 0.42, 0.40))
planks = []
for i in range(6):                                # 표면을 읽히게 하는 반복 디테일
    plank = lp.box(f"Plank{i}", size=(0.16, 0.06, 1.9),
                   location=(-0.9 + i * 0.36, -0.92, 1.05), rotation=(0, 0.06 * (i % 2), 0))
    lp.set_color(plank, (0.60, 0.50, 0.36) if i % 2 else (0.70, 0.60, 0.44))
    planks.append(plank)
anvil = lp.prism("Anvil", outline=[(-0.30, 0.0), (0.30, 0.0), (0.22, 0.18), (0.42, 0.30),
                                   (-0.42, 0.30), (-0.22, 0.18)], depth=0.26,
                 location=(1.5, -0.6, 0))
lp.set_color(anvil, (0.90, 0.42, 0.20))           # 악센트 — 시그니처 한 곳에만
forge = lp.join([body, roof, chimney, *planks, anvil], name="Smithy")
```
