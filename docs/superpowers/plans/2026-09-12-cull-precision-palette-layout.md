# 은면 컬링 정밀도 개선 + 팔레트 색상군 레이아웃 (2026-09-12)

## 문제
1. 마무리 단계 `cull_hidden_faces`가 보이는 면을 지운다.
   - 노멀이 안쪽을 향한 면(음수 스케일이 구워진 미러 파트, 손으로 만든 bmesh 면)은
     오프셋 샘플점이 자기 볼륨 안으로 들어가 **파트 전체가 은면 판정**된다 (재현: 6/6면).
   - 샘플점이 면 중앙 쪽(정점→중심 35%)에 몰려 있어 테두리만 노출된 면
     (받침대 윗면, 처마 아래 벽 윗면)이 통째로 지워진다.
   - 26방향 레이만 쓰므로 깊고 기울어진 오목 공간(관·컵 내부)이 막힘으로 오판될 수 있다.
2. 팔레트 텍스처가 "행=색상, 열=명도, 좌/우 절반=채도"라 사람이 UV로 색을 고르기 어렵다.

## 해법
### 컬링 (`lowpoly/cleanup.py`)
- 판정을 노멀 방향과 무관하게: 면 양쪽(±n) 오프셋 샘플 중 어느 하나라도 바깥을 보면 가시면.
- 샘플점을 정점 근처(94%)·변 중점 근처·중심으로 늘려 볼록한 가림체에 대해서는
  "모든 샘플 가림 ⇒ 면 전체 가림"이 보장되도록 한다.
- **포함 판정 추가**: 샘플점이 *다른 닫힌 아일랜드* 내부에 있어야만 은면 후보.
  오목 공간(열린 셸·컵·관 내부)은 닫힌 볼륨 안이 아니므로 절대 지우지 않는다.
  아일랜드는 remove_doubles 후 연결 요소로 나누고, recalc_face_normals로 바깥 노멀을
  맞춘 BVH의 `find_nearest` 부호로 내부 여부를 판정한다.
- 후보 면만 26방향 + 피보나치 64방향(양쪽 반구)으로 최종 확인.
- 검증: `tests/verify_cull_in_blender.py` (헤들리스) — 미러 파트 보존, 파묻힌 캡 삭제,
  적층 접촉면 삭제, 부분 노출 윗면 보존, 컵/기울어진 관 내부 보존.

### 팔레트 (`scripts/gen_palette.py` → PNG/palette_data 재생성)
- 256x256 유지, 셀 4x8px → 64열 x 32행 = 2048셀.
- 열(좌→우) = 색상 다양성: 무채색 4열(그레이/웜/세피아/쿨) + 색상 15개 x 채도 4단(선명→탁함).
  한 색상의 채도 4단이 16px 폭 한 덩어리(군집)로 붙는다.
- 행(아래→위) = 명도 32단. 텍스처 위가 밝고 아래가 어둡다.
- `GRID` 정사각 가정 제거: `COLS/ROWS/CELL_W/CELL_H`로 교체 (colorsnap, palette, 테스트).
- 기존 씬의 `LP3D_Palette` 이미지는 `_is_stale`이 픽셀 불일치를 감지해 자동 갱신된다.
  **기존 에셋의 UV가 가리키는 색이 바뀌는 파괴적 변경** — 사용자 요청에 따른 의도된 변경.
