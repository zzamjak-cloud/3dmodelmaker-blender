# 스타일 지침 — 사실적 (미드폴리)

과장 없이 **실제 비율과 실제 색**을 목표로 한다. 데포르메 규칙은 전부 적용하지 않는다.
다만 이것은 서브디비전 하이폴리가 아니라 **게임에 그대로 들어가는 미드폴리**다 —
형태는 사실적이되 메시는 여전히 손으로 관리 가능한 밀도여야 한다.

1. **과장 금지**: 특징 부위를 키우지 마라. 지붕·바퀴·손잡이·잎덩어리 모두 **실제 비율(95~105%)**로 만들어라. 공통 규칙의 질량 위계는 유지하되, 위계는 크기 조작이 아니라 실제 구조에서 나온다.
2. **치수를 먼저 정하라**: 코드 첫 주석에 실제 치수를 적고 시작하라 (예: `# 유럽식 목재 문: 폭 0.9m, 높이 2.05m, 두께 0.045m`). 짐작으로 만들지 말고 현실의 표준 치수를 근거로 삼아라. 문 손잡이는 바닥에서 1.0m, 계단 한 단은 높이 0.17m·깊이 0.28m, 벽돌은 0.21x0.10x0.06m다.
3. **곡률 세그먼트를 넉넉히**: `lathe`·`cylinder`는 segments 16~32, `sphere`는 subdivisions 2~3. 로우폴리의 8~16으로는 원통이 각져 보인다. `smooth=2`로 프로파일을 부드럽게 하라.
4. **모서리는 항상 베벨**: 실제 물체에 완전히 날카로운 모서리는 없다. 실루엣 파트에 `lp.bevel(width=0.003~0.01, segments=2)`를 작게 넣어라. 크게 넣으면 만화가 된다 — **1cm 이하**가 기준이다.
5. **폴리 버짓 (트라이 기준)**: 모델 전체 ≤ 60000. 프랍은 5000~20000, 건물은 30000~60000이 적정선이다. 버짓이 넉넉하다고 균일하게 쪼개지 마라 — 곡률과 실루엣에 몰아 쓰고 평면은 최소 분할로 둔다.
6. **구조를 실제 순서대로 쌓아라**: 건물은 기초 → 벽체 → 인방·문틀 → 창 → 처마 → 지붕 → 빗물받이 순으로, 가구는 프레임 → 판재 → 접합부 → 금속 부속 순으로 만들어라. 실제로 존재하는 부재를 빠뜨리면(문틀 없는 문, 처마 없는 지붕) 즉시 가짜로 읽힌다.
7. **색은 낮은 채도, 좁은 명도 폭**: 실제 재질의 색은 대부분 채도가 낮다. 나무는 회갈색, 콘크리트는 약간 푸른 회색, 페인트조차 바래 있다. 채도 높은 색은 도색된 금속·표지판 같은 실제로 선명한 대상에만 쓴다. 같은 재질의 2톤 차이는 **명도 5~15%**로 좁게 — 로우폴리처럼 크게 벌리면 만화가 된다.
8. **마모와 불균일**: 완벽하게 균일한 표면은 가짜로 보인다. 같은 부재를 반복 배치할 때 위치·회전에 **1~3%** 미세한 편차를 주고(`random.uniform`), 모서리 부재는 약간씩 다른 길이로 만들어라. 단 `lp.jitter`로 표면을 흔들지는 마라 — 그건 유기물 전용이다.

## 좋은 예시 (참고 패턴)

```python
# 사실적 목재 대문: 표준 치수(폭 1.6m, 높이 2.1m) + 실제 부재 구성 + 낮은 채도
# 부재: 문틀 2 + 상인방 + 문짝 2 + 띠장 4 + 경첩 4 + 손잡이 2
posts = []
for side in (-0.82, 0.82):                         # 문설주 — 0.12x0.12m 각재
    post = lp.box("Post", size=(0.12, 0.12, 2.24), location=(side, 0, 1.12))
    lp.bevel(post, width=0.006, segments=2)        # 1cm 이하 — 실제 모서리 마모
    lp.set_color(post, (0.36, 0.30, 0.24))         # 회갈색, 낮은 채도
    posts.append(post)
lintel = lp.box("Lintel", size=(1.88, 0.14, 0.18), location=(0, 0, 2.21))
lp.bevel(lintel, width=0.008, segments=2)
lp.set_color(lintel, (0.33, 0.27, 0.22))           # 같은 재질 2톤 — 명도 차 10%
leaves = []
for i, x in enumerate((-0.39, 0.39)):
    leaf = lp.box(f"Leaf{i}", size=(0.74, 0.045, 2.06), location=(x, 0, 1.05))
    lp.bevel(leaf, width=0.004, segments=2)
    lp.set_color(leaf, (0.42, 0.35, 0.27))
    leaves.append(leaf)
rails = []
for i in range(4):                                 # 띠장 — 반복이되 1~3% 편차
    z = 0.42 + i * 0.52 + random.uniform(-0.012, 0.012)
    rail = lp.box(f"Rail{i}", size=(1.56, 0.055, 0.12), location=(0, -0.05, z))
    lp.bevel(rail, width=0.004, segments=2)
    lp.set_color(rail, (0.30, 0.25, 0.20))
    rails.append(rail)
hinges = []
for i, (x, z) in enumerate([(-0.76, 0.40), (-0.76, 1.70), (0.76, 0.40), (0.76, 1.70)]):
    hinge = lp.box(f"Hinge{i}", size=(0.22, 0.03, 0.09), location=(x, -0.05, z))
    lp.set_color(hinge, (0.26, 0.26, 0.28))        # 무광 철물 — 채도 거의 없음
    hinges.append(hinge)
knobs = []
for i, x in enumerate((-0.10, 0.10)):
    knob = lp.lathe(f"Knob{i}", profile=[(0.018, 0.0), (0.030, 0.05), (0.022, 0.08)],
                    segments=20, smooth=2, location=(x, -0.07, 1.02))  # 손잡이 높이 1.0m
    lp.set_color(knob, (0.38, 0.33, 0.22))
    knobs.append(knob)
gate = lp.join([*posts, lintel, *leaves, *rails, *hinges, *knobs], name="WoodenGate")
```
